# AI as a Thinking Tool in the History Classroom (work sample)

A short work sample: three small interactive history demos built with AI (a sliding sea-level map, a drag-to-order timeline, and a Read, Ask, Decide evidence case), each with a note on how students use it.

Static site, no build step (`index.html`). Answers are saved only in the browser (localStorage). No data is sent anywhere. `noindex` and `robots.txt` block indexing.

Teachers should follow AIATSIS guidance and local community protocols for First Nations content.

Map drawn from NOAA ETOPO1 sea-floor depths; it shows the idea, not the exact coast at each time. Sources are cited on each card.
